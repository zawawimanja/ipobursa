## Session learnings

- User communicates in Malay ("ak projek ni" = "apa projek ni" = "what is this project?"); reply in Malay unless they switch.
- Runtime verified 15-Oct-2026: Node is available at `C:\Program Files\nodejs\node.exe`; bundled Node 24 is at `C:\Users\akaun\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`. Use `npm ci` for locked dependencies. Store-alias Python is not a working Python runtime.
- `data.js` and `data.json` are parallel sources of truth for the same IPO dataset (browser loads `data.js` via `<script src="data.js?v=...">`; Node scripts read `data.json`). When adding/updating IPOs, both must be kept in sync.
- `overrides.json` holds manual grade overrides applied on top of predicted grades (`apply-overrides.js`); predicted grades come from `predict_grades.js`/`audit-grades.js`.
- Static site deployed on Vercel (`vercel.json`, `@vercel/analytics`, single serverless fn `api/chat.js`). All seven pages load `data.js?v=4.9` and `index.html` also loads `sync-status.js?v=2.0` — bump every `data.js?v=` together when data changes (they were drifting apart until 22-Oct-2026).
- IPO records live in a 5-stage lifecycle (1 Draft → 2 MITI/Bumi → 3 Public → 4 Pre-Listing/balloting → 5 Listed); `stage` field is 1–5, graded A/B/C/Pending via OS (oversubscription), PE, sector.
- `scratch/` holds dozens of one-off analysis/backtest scripts operating on `data.json`; `archive/` and `*.csv` exports are historical snapshots.
- **iSaham (isaham.my) is fully behind Cloudflare Turnstile**: plain axios/fetch, webfetch, proxies (r.jina.ai, allorigins), and Puppeteer (headless OR headed, even with saved profile/cf_clearance) all get 403/challenge — only `sitemap.xml`/`robots.txt` are unblocked. Do NOT spend time on Puppeteer/keeper approaches.
- **iSaham is optional and disabled in automatic sync by the user's choice (15-Oct-2026).** Official docs at https://api.isaham.my/docs now require Max access for `/v1/ipo/upcoming` and `/v1/ipo/live` (5 credits each); `/v1/account/usage` is free. A Free token alone does not provide IPO access. Keep `sync-isaham-api.js` as a manual utility; do not re-enable it or buy access without the user asking.
- **Automatic sync uses KLSE Screener for public IPO schedules and balloting, i3investor for prices, and MITI for MITI offers.** Both `bursa.js` and GitHub Actions use those sources. API and scraper failures must preserve existing data and report the actual failure; they are not successful refreshes.
- `sync-isaham.js` fetch chain: fresh cache (26h) → axios → axios+cookies Chrome (primary) → `scrape-isaham.js --quiet --fresh` (Puppeteer, 260s timeout) → stale cache; tracks `isahamNetworkOk` and prints a loud `DEGRADED` summary + Telegram alert when everything fails.
- `.env` is gitignored and holds secrets (`ISAHAM_API_TOKEN`, `GROQ_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, MITI creds).
- **MITI changed to a Filament/Livewire portal.** `scratch/sync-miti-portal-dates.js` reads public opening/closing dates; `scratch/sync-miti-applicants-login.js` reads authenticated offer details using Puppeteer and `MITI_USERNAME`/`MITI_PASSWORD`. The new portal no longer exposes applicant counts. GitHub has both MITI secrets, but no local credentials were configured on 15-Oct-2026. The 14-Oct run returned HTTP403 from the portal on the GitHub runner; a local public request later returned HTTP200. A missing login form must be reported as an access/session failure, never as an empty successful sync. Node24 is used by Actions for Puppeteer25 compatibility. Do not claim the cloud sync is restored until a real runner succeeds.
- **The MITI public announcement only publishes company name + open/close dates** (verified 22-Oct-2026 against the live portal HTML) — no price, board, sector or IB. Records created from MITI therefore start `market: Unknown, price: 0` and grade as Unrated until KLSE lists them.
- **KLSE Screener card tickers are authoritative**; stored symbols had drifted (RedPlanet is `RPLANET`, not `REDPLANET`; several records hold a company name in `symbol`, e.g. `GTA Holdings Berhad`, which makes i3investor answer with its homepage). `sync-public-ipos.js` now replaces a mismatched symbol and fills missing `market`/`sector` from the card's Board/Sector labels, including for Stage 5 records. `scratch/probe-i3-symbol.js <TICKER...>` checks a counter on i3 (prints title, historical-chart code, first dtdata row).
- **i3investor throttles around 50 rapid requests (HTTP 429) and stops indexing brand-new counters for a short while.** `scrape-i3.js` now retries 429/403 with `Retry-After`/escalating waits, doubles an adaptive inter-request delay on throttling and halves it on success, and skips symbols containing spaces. Verified live 22-Oct-2026: 118 counters, no 429 failures.
- **Missed debut prices are recoverable** from `https://klse.i3investor.com/web/stock/historical-chart/<numericCode>` (`var dtdata = [["YYYY-MM-DD","open","high","low","close",...]]`, code parsed from the overview page link). `scrape-i3.js` backfills `openPrice` from that row for Stage 5 records without one, bounded to 14 days after listing (`DEBUT_BACKFILL_WINDOW_MS`); older gaps need a manual one-off. Debut rows are only available some time after the listing, so a same-day run may still miss them.
- `package-lock.json` was deleted in 60adbdf, which broke every scheduled run because both workflows use `npm ci`; restored 22-Oct-2026 (commit 9f95756). Do not delete it again.

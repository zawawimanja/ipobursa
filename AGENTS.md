# AGENTS.md

## Session learnings

- User communicates in Malay ("ak projek ni" = "apa projek ni" = "what is this project?"); reply in Malay unless they switch.
- `node` and `python`/`python3` are NOT on PATH in the tool shell (Windows Git Bash, home `C:\Users\akaun`). The python/py found in `AppData/Local/Microsoft/WindowsApps` are Store-alias stubs that only print "Python was not found". Scripts like scraper.js/audit-*.js cannot be executed from the shell here; treat their output files as pre-generated.
- `data.js` and `data.json` are parallel sources of truth for the same IPO dataset (browser loads `data.js` via `<script src="data.js?v=...">`; Node scripts read `data.json`). When adding/updating IPOs, both must be kept in sync.
- `overrides.json` holds manual grade overrides applied on top of predicted grades (`apply-overrides.js`); predicted grades come from `predict_grades.js`/`audit-grades.js`.
- Static site deployed on Vercel (`vercel.json`, `@vercel/analytics`, single serverless fn `api/chat.js`). `index.html` cache-busts `data.js?v=2.1` and `sync-status.js?v=2.0` — bump the version query when the data changes.
- IPO records live in a 5-stage lifecycle (1 Draft → 2 MITI/Bumi → 3 Public → 4 Pre-Listing/balloting → 5 Listed); `stage` field is 1–5, graded A/B/C/Pending via OS (oversubscription), PE, sector.
- `scratch/` holds dozens of one-off analysis/backtest scripts operating on `data.json`; `archive/` and `*.csv` exports are historical snapshots.
- **iSaham (isaham.my) is fully behind Cloudflare Turnstile**: plain axios/fetch, webfetch, proxies (r.jina.ai, allorigins), and Puppeteer (headless OR headed, even with saved profile/cf_clearance) all get 403/challenge — only `sitemap.xml`/`robots.txt` are unblocked. Do NOT spend time on Puppeteer/keeper approaches.
- **iSaham has an official REST API** at `api.isaham.my/v1` (docs: api.isaham.my/docs): `Authorization: Bearer <token>` from https://api.isaham.my/portal/dashboard (log in with iSaham account, token shown once), token stored in `.env` as `ISAHAM_API_TOKEN`. Free tier = 500 credits/month (rate 2/s): `/v1/ipo/upcoming` = 5cr, `/v1/ipo/live` = 5cr, `/v1/account/usage` = 0cr. 1 run/day = 10cr = 300/mo.
- **Sync flow (`bursa.js`)**: 08:45 run uses `sync-isaham-api.js` (official API, primary — no 403 ever); 13:00/17:30 runs use `sync-isaham.js` (scrape + Chrome session cookies from `scratch/isaham-cookies.json`, dumped by `scratch/dump-isaham-cookies.py` after logging into isaham.my once in Chrome). API failure falls back to scrape; scrape failure keeps existing data and sends Telegram alert if `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` set.
- `sync-isaham.js` fetch chain: fresh cache (26h) → axios → axios+cookies Chrome (primary) → `scrape-isaham.js --quiet --fresh` (Puppeteer, 260s timeout) → stale cache; tracks `isahamNetworkOk` and prints a loud `DEGRADED` summary + Telegram alert when everything fails.
- `.env` is gitignored and holds secrets (`ISAHAM_API_TOKEN`, `GROQ_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, MITI creds).
- **MITI applicant sync = LOGIN TERUS, bukan cookies**: portal SahamOnline MITI (`sahamonline.miti.gov.my`) gunakan Google reCAPTCHA pada form login, TETAPI server TIDAK enforce ia — POST `_csrf` + `LoginFormPublic[username]` + `LoginFormPublic[password]` + `rememberMe` terus berjaya (tested 20-Aug-2026). `scratch/sync-miti-applicants-login.js` buat login+scrape+update data (JSON/JS/export/overrides) tanpa cookies Chrome/CAPTCHA. Kredential dari `.env` atau env vars (`MITI_USERNAME`/`MITI_PASSWORD`). GitHub Actions (`.github/workflows/update-ipo-data.yml`) jalankan ia 3×/hari guna secrets `MITI_USERNAME`/`MITI_PASSWORD` — laptop tak perlu on, cookies Chrome (`miti-cookies.json`) & `browser_cookie3` TIDAK lagi diperlukan (App-Bound Encryption Chrome 127+ mematahkan decrypt).
